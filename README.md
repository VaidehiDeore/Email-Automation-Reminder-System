# 📧 Email Automation & Reminder System

A full-stack automation platform that schedules and manages automated email reminders using Python, FastAPI, CSV-based workflow simulation, and a premium Next.js dashboard.

---

# 🚀 Features

✅ Email reminder automation
✅ CSV-based contact management
✅ Dynamic email personalization
✅ FastAPI backend APIs
✅ Downloadable reports
✅ Logging system
✅ Live analytics dashboard
✅ Add Contact & Add Reminder forms
✅ Interactive charts and graphs
✅ Dry-run email simulation

---

# 🛠 Tech Stack

## Backend

* Python

# ⚙️ Installation

## Clone Repository

```bash
git clone 
cd Email-Automation-Reminder-System
```

## Create Virtual Environment

### Windows

```powershell
python -m venv venv
.\venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Frontend Setup

```bash
cd dashboard
npm install
```

---

# ▶️ Run Project

## Backend

```powershell
cd Email-Automation-Reminder-System
.\venv\Scripts\activate
uvicorn api:app --reload
```

## Frontend

```powershell
cd dashboard
npm run dev
```

Frontend URL:

```text
http://localhost:3000
```
